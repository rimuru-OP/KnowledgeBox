
# KnowledgeBox

An AI-powered personal knowledge assistant that allows
users to upload documents and interact with them using
Retrieval-Augmented Generation (RAG).

## Features

- Document upload and processing
- Intelligent text chunking
- Semantic search using embeddings
- Vector storage with ChromaDB
- Context-aware AI responses
- Source references in answers

## Tech Stack

- React + TypeScript
- Python + FastAPI
- Google Gemini
- Sentence Transformers
- ChromaDB
- PyMuPDF

## Architecture

Document Upload → Text Extraction → Chunking →
Embeddings → Vector Database → Retrieval → LLM Response
